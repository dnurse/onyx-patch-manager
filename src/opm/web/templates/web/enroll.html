REMOTE SSH HOST KEY
ED25519 fingerprint

This fingerprint comes from the network and is not independently authenticated. Comparing it with a trusted record provides stronger protection. If you choose to trust it on first use, you accept the risk of connecting to the wrong server.

After you confirm, OPM will:
  1. Trust the approved SSH host key.
  2. Generate or reuse the controller's SSH identity.
  3. Use your temporary administrator credentials to create the opm user.
  4. Install the OPM public key and configure password-required sudo.
  5. Test SSH key login and the new sudo password.
  6. Automatically scan APT packages and Docker/Podman using the verified OPM sudo authorization. This can refresh APT package indexes but will not install upgrades or restart containers.

Provisioning and verification are running in the background. You may leave this page and monitor Activity.
