03

Set up and test

OPM will repeat the SSH identity check, perform your selected account action and verify the new controller's SSH access and the opm sudo password.

After you confirm, OPM will:
  1. Trust the approved SSH host key.
  2. Generate or reuse the controller's ED25519 SSH identity.
  3. Perform the selected remote OPM account action.
  4. Install the new controller public key and verify SSH authentication.
  5. Test sudo using the supplied opm password.
  6. Scan APT packages and Docker/Podman after successful verification. Package upgrades and container restarts are not performed during onboarding.

Provisioning and verification are running in the background. You may leave this page and monitor Activity.
