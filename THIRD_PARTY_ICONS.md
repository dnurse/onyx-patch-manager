property of their respective owners. No endorsement is implied.
The server UI controls the displayed color and shape; the SVG artwork retains its original paths. A vendor-themed fill color
is applied to each SVG for legibility on OPM's dark background.

## Optional application icons from Dashboard Icons

Where Docker Hub publishes no application artwork, OPM can fetch a PNG for
**explicitly mapped repositories only**, from the community-maintained
[Dashboard Icons](https://github.com/homarr-labs/dashboard-icons) collection.
Project source: https://github.com/homarr-labs/dashboard-icons
License: Apache License 2.0 (repository), subject to individual brand trademark
rights. OPM does not bundle these application icons; it caches approved PNGs
locally after retrieval. No third-party URLs are sent to the browser.
