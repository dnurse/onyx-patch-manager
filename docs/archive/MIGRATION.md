# OPM Migration Notes

The current migration and installer instructions for OPM v0.4.0 are in
[UPGRADE.md](UPGRADE.md) and [README.md](README.md).

Do not manually rename, replace, or delete the existing SQLite database.
The installer preserves it and creates a consistent backup before migration.

For v0.4.3, there is no database or credential migration. Follow UPGRADE.md.
